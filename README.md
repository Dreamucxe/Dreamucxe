## About

I build **Android apps in Kotlin** — Jetpack Compose, Material 3, MVVM, Hilt — and they are
offline-first by default: no backend, no account system, no analytics, nothing uploaded.

Most of what I ship is a tool rather than a toy: a gaming overlay that measures instead of
guessing, a process observatory, a storage analyzer, an APK inspector, a terminal emulator.
They share one rule — **never show a number the device didn't actually report.** If a reading
isn't available on your hardware, the app says so plainly instead of inventing one.

- 🔨 Kotlin · Jetpack Compose · Material 3 · Coroutines · Room · Hilt
- 🔒 Privacy by construction — encrypted local storage, no cleartext traffic, no telemetry
- 🧪 Tested against pure, Android-free seams so the suite runs on any JDK, no emulator
- 📱 Everything ships as a signed APK you can install and read the source of
